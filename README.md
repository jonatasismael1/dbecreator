# DBE Creator 🚀

O Sistema Operacional para Criadores de Conteúdo Estratégico.

## 📝 Sobre o Projeto
O **DBE Creator** é um SaaS projetado para ajudar freelancers, social medias e experts a transformarem ideias em Reels de alta conversão. Através da metodologia DBE e da inteligência da **Deby**, nossa diretora de conteúdo em IA, o usuário tem um fluxo completo de produção.

## 🛠 Stack
- **Frontend:** React, TypeScript, Tailwind CSS, shadcn/ui
- **Backend/DB:** Supabase
- **IA:** OpenRouter
- **Animações:** Framer Motion

## 🚀 Como Rodar Localmente

```bash
git clone <repo-url>
cd dbe-creator
cp .env.example .env.local
# Preencha as chaves do Supabase no .env.local
npm install
npm run dev
```

## 🔑 Variáveis de Ambiente
Veja `.env.example` para a lista completa. As chaves sensíveis (OpenRouter, Service Role) **nunca** devem ir para o frontend.
